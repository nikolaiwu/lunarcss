Details & Summary

What is LunarCSS?

LunarCSS is a classless CSS framework that provides beautiful default styles for all standard HTML elements. Just include the CSS file and your HTML will look great!

How do I use it?

Simply add the LunarCSS stylesheet to your HTML document. No classes required—the framework styles all elements using element selectors.

Can I customize it?

Yes! LunarCSS uses CSS custom properties (variables) for all colors, spacing, and typography. Override the variables in your own stylesheet to create a custom theme.
