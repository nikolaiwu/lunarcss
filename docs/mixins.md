# Mixins

[src/scss/mixins/](../src/scss/mixins/) holds one file per mixin. `_index.scss` `@forward`s them all, so modules import them with `@use "../mixins"` and call `mixins.<name>`. The folder isn't in `main.scss` and emits no CSS on its own. Add new mixin files to `_index.scss`; a mixin that uses another one `@use`s that sibling file directly (as `_card.scss` does with `cut-corner`).

- `cut-corner-border($corners, $size, $border-width, $border-color, $background)` draws a bordered box with 45° cut corners. `clip-path` can't draw a border along the diagonal, so `::before` is the border shape and `::after` is the fill, inset by the border width (the inner cut is `size − width × 0.5858`). It takes over the host's `::before` and `::after`, and sets `position: relative`, `isolation: isolate`, `border: 0` and a transparent background. A host box-shadow would show as a rectangle past the cuts. The `cut-corner-polygon()` function is forwarded too, for overriding single corners (see the button groups).
- `card` is the full card look (padding, cut-corner border, `> header` dashes, `> footer` stripes). A host that needs its own `position` or other overrides should put them in a `& { … }` block after the `@include`, so they come after the mixin's output (see `dialog`).
- `dotted($size, $gap, $color)` paints a repeating dot grid (one `radial-gradient` tile); `hr` uses it as a band. Overrides: `--lunar-dot-size`, `--lunar-dot-gap`, `--lunar-dot-color`.
- `striped($width, $gap, $angle, $color, $height)` paints repeating diagonal stripes; with `$height` it confines them to a full-width band of that height (`background-size` and `no-repeat`; the caller sets `background-position`), overridable with `--lunar-stripe-height`; the card footer, table footer and blockquote bands use it, and so does `striped-label`. Overrides: `--lunar-stripe-width`, `--lunar-stripe-gap`, `--lunar-stripe-angle`, `--lunar-stripe-color`, `--lunar-stripe-height`.
- `striped-label($lead, $space, $width, $gap, $color)` sets the host's text into a striped rule: the host becomes a flex row, its bare text an anonymous flex item, with `::before` (`$lead` long) and `::after` (the rest) carrying `striped` on either side, stretched to the line height. It takes over the host's `::before` and `::after`. The legend uses it.
- `dotted` and `striped` set only `background-image` (plus size and repeat for a `striped` band), so the host keeps its own background color.
- `ruler($count, $color, $width, $height, $track)` draws tick marks along the bottom edge, evenly spread with none on the edges; range, progress, meter and the table header cells use it. `$track` adds a bar-height layer above the ticks, for engines with no track pseudo-element. `$start: true` adds a major tick on the left edge (five times as long, in `$start-color`), which the table header uses to mark column starts.
- `brackets($color, $size, $inset)` draws corner brackets (an L-mark per corner, eight background layers). It also exposes `bracket-images()`, `bracket-positions()` and `bracket-sizes()` as functions, so a caller that needs other layers in the same background can build one list rather than fight over `background-image`. The functions take `$corners` to mark only some corners (the blockquote panel uses the right two); pass the same list to all three.
- `field($ticks, $lead-image, …)` is shared by text fields, textareas and selects: brackets, plus a tick ruler parked below the border box. `field-focus` re-declares two custom properties (bracket size and tick position), and the mixin's transitions animate the rest. `$lead-image` adds a layer on top, for the select chevron. `$bracket-corners` limits the brackets to some corners; textarea drops the bottom-right one, which would sit on the resize handle.
- Form controls give us no pseudo-elements to work with (`input` is void; `textarea` and `select` don't render `::before`/`::after`), which is why all of this is background layers.
- Runtime overrides for users: `--lunar-cut-size`, `--lunar-cut-border-width`, `--lunar-cut-border-color`, `--lunar-cut-bg`.
