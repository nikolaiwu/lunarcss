# Components

- **Cards:** `article` is the classless card ([elements/\_article.scss](../src/scss/elements/_article.scss)), with optional `header` (irregular dashed rule below it) and `footer` (45° striped band above it). The look comes from the `card` mixin, shared with `dialog`, with local `--_card-*` properties at its top. The card grid lives in the layout stylesheet.
- **Buttons:** [elements/\_buttons.scss](../src/scss/elements/_buttons.scss) holds `button` and the input button types, cut at top-right and bottom-left via `cut-corner-border`, plus the grouping rules. Adjacent form controls drop the cuts where they touch (`:is(button, input, select, textarea)` adjacency, with `button` always the subject, since void elements have no pseudo-elements). The fill is the mixin's `::after`, so states set `--lunar-cut-bg` rather than `background-color`, and the host background must stay transparent. Group spacing comes from the layout stylesheet.
- **Checkboxes and radios:** [elements/\_checkboxes.scss](../src/scss/elements/_checkboxes.scss) and [elements/\_radios.scss](../src/scss/elements/_radios.scss). Both replace the native control with `appearance: none` and are drawn entirely on the element — `input` is void, so there are no pseudo-elements. The checkbox is a vertical switch as tall as `--lunar-control-height`, its knob a gradient moved with `background-position` and colored through `color` (gradients can't transition, `color` can). The radio is a circle filled by a `conic-gradient` whose stop is the registered `--lunar-radio-fill`; registering it with `@property` is what makes it animatable.
